# Obra da Casa

Plataforma para combinar os serviços da obra entre Carlos e Júlio: cadastro por áudio e foto, sugestão de execução e materiais pelo Claude, orçamento, aprovação com PIN, calendário e avisos por e-mail.

- `index.html` — a página (GitHub Pages).
- `apps-script/Code.gs` — o backend (Google Apps Script): planilha, Drive, Gmail, transcrição (Groq) e API do Claude.

Chaves de API ficam só nas Propriedades do script, nunca neste repositório.
